# Parho Study Notes & PDF Storage

Place your local PDF files in this directory structured by `courseId/subjectId/`:

```text
storage/notes/
├── ppsc/
│   ├── general-knowledge/
│   │   ├── general-knowledge-1.pdf
│   │   ├── general-knowledge-2.pdf
│   │   └── general-knowledge-3.pdf
│   ├── pakistan-affairs/
│   ├── english/
│   ├── current-affairs/
│   ├── islamic-studies/
│   ├── everyday-science/
│   └── basic-mathematics/
├── fpsc/
├── nts/
├── css/
└── pms/
```

### Supported File Naming:
You can name your files matching either:
1. The PDF ID (e.g. `general-knowledge-1.pdf`)
2. Or any `.pdf` placed in the subject folder will automatically be indexed and served!

### Security & Anti-Piracy:
Files inside `storage/notes/` are protected by the Parho API. Only authenticated, active students enrolled in the corresponding course can stream them, and the in-app reader automatically stamps their Email and WhatsApp Number across every page as a tamper-evident watermark.
